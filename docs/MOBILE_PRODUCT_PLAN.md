# Mobile Product — 2026-11-13

## 审计结论
当前为 Vue + Pinia + hash Router，已存在 Capacitor Android 壳、Supabase服务、PWA与同步逻辑。本轮保留这些实现，不重建工程、不发布安装包。Design.md 的 Neo Athletic 配色为视觉依据。

主要问题：所有业务页面共用固定底栏；课程页面采用桌面抽屉；移动表单仍双列；尚无 Capacitor 系统返回适配；搜索和滚动上下文需要恢复。既有课程状态、可用性、评分与持久化服务可以复用，不在视图另建业务状态。

## 分阶段实施
1. 应用外壳：按路由层级隐藏底栏，移动表单与安全区，系统返回适配。
2. 页面上下文：列表搜索与位置、课表日期视图、排课来源返回；压缩首页与移动周视图。
3. 短流程：统一Bottom Sheet、选择与筛选、焦点/关闭/未保存保护。
4. 训练记录与反馈：沿用评分，补充轻量训练内容和下次建议；统一提交反馈。
5. 真机回归：USB Android 返回、键盘、滚动、安全区、前后台、A–E业务流程；自动化与构建回归。

预计涉及 app/App.vue、app/main.ts、composables、平台适配服务、views、components和对应styles；每阶段独立验证。保留桌面可操作性，不扩展管理后台。

## 真机与风险
2026-11-13：正常进程环境中ADB启动成功，`adb devices -l`为空。已请求用户连接手机并授权USB调试。设备未连接前不宣称真机验收通过。不清除手机应用数据，不安装或覆盖已有包；优先USB端口转发访问开发服务器。原生系统行为需在现有可调试容器中另行验证。

本轮不存在不可逆迁移、技术栈替换或付费服务；不将浏览器尺寸测试当作Android实机结果。
