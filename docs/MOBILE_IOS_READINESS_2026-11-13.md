# Tempo 移动界面改造与 iOS 发布准备 · 2026-11-13

## 本轮落地
- 移除深色标题横幅、斜杠和粗分隔线，课表、学员、我的统一浅色无卡片标题层级。
- 深石墨色排课按钮配荧光绿加号，保留运动品牌而降低装饰密度。
- 全宽日/周/月切换；日期导航去卡片化；今天/下一节及待办红点保持一行。
- 移动底栏改成浅色，仅选中图标使用荧光绿；学员列表使用连续分隔行。
- 保持完整七列周视图、单层纵向滚动、任务页隐藏底栏和返回恢复。

## 本地验证
- TypeScript 与生产构建通过。
- 四种手机宽度（360/375/390/430）和桌面：课表、来源返回、待办弹层共 15 项通过。
- 已检查手机周课表、我的页面截图；未进行 iPhone 真机、VoiceOver、系统大字体或 iOS 键盘验证。
- 此轮仅改展示层，未修改课程、评分、课包或数据持久化逻辑。

## 发布前仍需完成
1. 当前依赖含 Android 容器，未配置 @capacitor/ios。需在 macOS / Xcode 建立 iOS 工程，配置签名，测试 WKWebView、安全区、键盘、返回和前后台恢复。
2. 真实后端账号隔离、离线重连、备份恢复和失败处理需要发布环境验收；本地浏览器测试不能替代。
3. src 中未发现用户可见隐私政策或账号删除入口。需落实真实数据处理政策、支持入口；若提供注册，须提供应用内账号删除及服务端删除流程。
4. 准备审核可用账号或完整演示模式、支持与隐私 URL、真实截图和准确的数据收集披露。
5. 逐项完成 iPhone 无障碍与大字体、横屏、小屏、弱网和首次启动验收。
