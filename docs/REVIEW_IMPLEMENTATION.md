## 第二批：套餐与可靠提交

**可靠提交已完成（2026-11-13 晚）。** 同步队列从内存数组改为落盘 outbox（`src/services/outbox.ts`）：每项带 `id/createdAt/attempts`，成功才出队，失败保留队首并记录尝试次数；`bootRemote` 启动时接回上次未提交的操作并继续推送，推送成功后重取一次快照对齐；队列按账号分键，退出登录只断开连接、不清队列。刷新、断网、崩溃不再丢操作。7 条队列单测覆盖出队/失败停住/重放去重/损坏存储降级/账号分键。
