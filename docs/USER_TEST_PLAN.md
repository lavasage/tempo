## PWA 实机检查清单
1. Android Chrome：地址栏出现安装提示或页内安装卡片；安装后从主屏启动无浏览器栏；断网启动能看到上次课表。
2. iOS Safari：不出现安装卡片，而是「分享 → 添加到主屏幕」文字指引；加入主屏后从图标启动为独立窗口；断网启动不白屏。
3. 键盘（桌面）：首个 Tab 是「跳到主要内容」，回车后焦点进入正文且地址栏 hash 不变。
4. 安全区：iPhone 刘海/底部横条不遮挡底部导航与页尾；横屏下表单不被裁切。
5. 升级：部署新版本后重新打开，出现「新版本已就绪」，点「立即更新」后内容更新且本地数据不丢。
